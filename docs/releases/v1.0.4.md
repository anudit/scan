Scan v1.0.4 reloads a file when it changes on disk, fixes NDJSON files whose fields appear late, and shows row counts with US-style commas.

- **Auto-refresh:** while a file is open, Scan watches it and reopens it when it changes on disk, including when an editor replaces the file on save. Filters, sorts and grouping reset on refresh.
- **Fix:** an NDJSON or JSON Lines file with a key that first appears after the first 2,048 rows, for example a nested `adType`, no longer fails to open with "has unknown key". Scan now reads the whole file to work out its columns, so opening a very large file takes longer.
- **US number format:** row and group counts, the copy-rows prompt and the memory-limit message always group digits as `159,729`, whatever the system region is.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.0.4-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
