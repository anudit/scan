Scan v1.0.3 opens NDJSON files, shows JSON cells as a tree you can expand, and gives each file type its own icon.

- **NDJSON:** `.ndjson` and `.ndjson.gz` files open like JSON Lines, with each field as a typed column. Before, they were read as CSV and showed as one text column. Finder's Open With and Quick Look also cover them.
- **JSON tree in the inspector:** when a cell holds a JSON object or array, the Cell inspector shows it as a tree you can expand and collapse, with keys in the file's order. Right-click a row to copy its value, key or DuckDB JSON path (for example `$.maker.links[0]`). Switch between Tree and Text with the control beside the column name. Struct, list and map columns show as JSON too, and copying their cells now gives JSON.
- **File type icons:** tabs and the sidebar show a different icon for each format: CSV/TSV, JSON Lines, Parquet, and SQLite/DuckDB.
- **Fix:** a struct column containing a list, such as `STRUCT(handle VARCHAR, links VARCHAR[])`, no longer stops the file's rows from loading with "ARRAY_SLICE can only operate on LISTs".

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.0.3-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
