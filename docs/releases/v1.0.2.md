Scan v1.0.2 makes deep row jumps and Quick Look much faster, and adds a light theme and more export formats.

- **Fast jumps deep into Parquet files:** Scan's DuckDB Parquet reader now skips whole pages using their headers (and the page index when the file has one) instead of decoding every skipped row. Jumping to row 300,000 of a 1 GB file with one large row group and an embedding column now takes 161 ms instead of 757 ms, or 47 ms with a page index. A jump loads its visible rows in one query, and text columns appear before list and binary columns.
- **Faster Quick Look:** CSV, TSV and JSONL previews read only the head of the file and detect its format once. On a 200 MB file, a `.csv.gz` preview now takes 34 ms instead of 1,045 ms, and CSV, TSV and JSONL previews take 9–33 ms. Previews follow the system's light or dark mode.
- **Light theme:** choose System, Light or Dark in **Settings → Appearance**. Dark remains the default.
- **Export formats:** export the current view as CSV, JSON, JSON Lines or Parquet.
- **Inspector:** shows a cell's value immediately, fetching only that column when the grid's copy is shortened. Long values wrap, and you can drag the inspector's left border to resize it.
- **Opening files:** opening a file from Finder or `scan` on a cold launch now shows it, and the first window has its title bar tabs.
- **Grid:** applying a filter or sort returns to the first row, sorted columns show an ASC or DESC badge, and the row number column fits six-digit and longer row numbers.
- **New icon:** Finder shows the full app icon on files that Scan opens by default.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.0.2-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.

## Validation

All 30 tests passed, including new tests for export formats, column-subset pages and head-sampled previews of quoted multi-line and gzip files. The patched Parquet reader returned identical results to stock DuckDB 1.5.6 on 15 files, covering about 400 random row ranges plus a full-table hash per file. The files spanned v1 and v2 data pages, page indexes, dictionary and plain encoding, nulls, lists, nested lists, structs and four compression codecs.
