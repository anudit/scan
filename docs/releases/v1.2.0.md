Scan v1.2.0 opens many more kinds of data: Excel workbooks, JSON arrays, GeoJSON, zstd-compressed text and whole folders of files.

- **Excel:** open `.xlsx` workbooks. Each sheet is listed under **Tables**. Rows below blank rows are kept, and if a cell does not match its column's type, the sheet is read as text so no value is lost. Legacy `.xls` files are not supported.
- **JSON and GeoJSON:** `.json` files holding an array of objects, one object per line, or a single object. `.geojson` FeatureCollections open with one row per feature, properties as columns and the geometry as JSON.
- **Folders:** open a folder, or run `scan path/to/folder`, to read all of its Parquet, CSV/TSV or JSON Lines files as one table. Files with different columns are combined by name, and Hive-partitioned folders such as `year=2024/` become columns.
- **zstd:** CSV, TSV, JSON, JSONL and GeoJSON files compressed with zstd (`.zst`, `.zstd`), in the app and in Quick Look.
- **More extensions:** pipe-delimited `.psv`, `.tab`, `.txt` and `.dat` text; `.parq` and `.pq` Parquet; `.db3`, `.s3db` and `.sl3` SQLite. Databases are identified by their header, so a DuckDB file named `.db` now opens correctly.
- **Remote files:** **File → Open URL…** also accepts CSV, JSON, Excel and the other formats above. Parquet is still read on demand with range requests; other files are downloaded in full into the remote cache.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.2.0-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
