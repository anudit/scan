Scan v1.3.0 adds column profiles, click-to-filter, saved views per file, and reading from Amazon S3, Google Cloud Storage and Cloudflare R2. It also includes the file formats and interface polish prepared for v1.2.0, which was not published separately.

## New in v1.3.0

- **Column profiles:** the inspector's new **Profile** tab shows a column's row, NULL and distinct counts, its min, max and mean, a histogram and its most common values. It follows the selected column. Click a histogram bar or a value to filter to it. Numeric column headers show a small distribution chart.
- **Click a value to filter:** right-click any cell for Only, Exclude, Greater Than, Less Than, Contains or Exclude NULL. The condition is added to the current filter, which stays editable.
- **Top values in the sidebar:** the arrow beside each column lists its most common values with counts. Click one to filter to it.
- **Saved views:** each file remembers its filter, sorts, hidden and reordered columns, column widths and heatmaps. **Reset View** (the curved arrow in the toolbar) forgets them.
- **Cloud storage:** open `s3://`, `gs://` and `r2://` URLs from **File → Open URL…** or the CLI, through the same range reader and cache as HTTPS files. Public buckets need no keys. For private ones, add keys in **Settings → Cloud Storage**, or set `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY`, `GCS_ACCESS_KEY_ID`/`GCS_SECRET_ACCESS_KEY`, or `R2_ACCOUNT_ID`/`R2_ACCESS_KEY_ID`/`R2_SECRET_ACCESS_KEY`. The S3 bucket region is found automatically, and S3-compatible servers such as MinIO work through a custom endpoint.
- **Smoother scrolling:** scrolling draws only the newly revealed rows, laid-out text is evicted gradually instead of all at once, and rows load ahead in the direction you scroll.

## Also included (prepared as v1.2.0)

- **Heatmaps:** color a numeric column from green at its minimum to red at its maximum, from the toolbar, a header or the sidebar.
- **Interface:** springy, rubber-banding sidebar and inspector edges with a glow that follows the pointer, a sliding tab picker, hover states, and a rounded focus ring.
- **Excel:** open `.xlsx` workbooks. Each sheet is listed under **Tables**. Legacy `.xls` files are not supported.
- **JSON and GeoJSON:** `.json` arrays of objects, one object per line, or a single object. `.geojson` FeatureCollections open with one row per feature.
- **Folders:** open a folder, or run `scan path/to/folder`, to read all of its Parquet, CSV/TSV or JSON Lines files as one table, including Hive-partitioned folders.
- **zstd:** CSV, TSV, JSON, JSONL and GeoJSON files compressed with zstd (`.zst`, `.zstd`).
- **More extensions:** `.psv`, `.tab`, `.txt`, `.dat`, `.parq`, `.pq`, `.db3`, `.s3db` and `.sl3`. Databases are identified by their header.
- **Remote files:** **File → Open URL…** also accepts CSV, JSON, Excel and the other formats above; they are downloaded in full into the remote cache.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.3.0-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
