Scan v1.1.0 opens Parquet files straight from an HTTPS URL, including Hugging Face datasets, without downloading the whole file.

- **Remote Parquet:** choose **File → Open URL…** (⇧⌘O) or run `scan https://…/file.parquet`. Hugging Face `/blob/` links are rewritten to `/resolve/`. Scan reads the footer and only the columns and row groups needed for the visible rows, using HTTP range requests.
- **Fast open:** one request returns the file size, its validators and the footer. Neighbouring column chunks share a request, up to six downloads run in parallel, and downloads stream straight into the cache. Scrolling forward fetches the next row group in the background.
- **Cache:** downloaded data is kept in a sparse cache at `~/Library/Caches/dev.scan.app/RemoteParquet`, capped at 5 GB with least-recently-used eviction. Reopening a file fetches only what is missing. Clear it from **Settings**.
- **Private repositories:** save a Hugging Face token in **Settings → Hugging Face** (stored in the login keychain), or set `HF_TOKEN`. The token is only sent to Hugging Face and is dropped when a request is redirected to another host.
- Filters, sorts, grouping, export and Ask download the remaining data first. The status bar shows how much of the file is cached.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.1.0-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
