Scan v1.4.0 opens very large JSON Lines files quickly, redesigns the interface around resizable side panels and an interactive SQL panel, and can check for and install updates.

## New in v1.4.0

- **Large JSONL files:** files over 32 MB are indexed by line position, so opening, scrolling, filtering and sorting never parse the whole file. A 1.7 GB, 634k-row file now opens in seconds instead of failing.
- **SQL panel:** the filter bar moved to a panel at the bottom (⌘J). It has Filter, SQL and Ask modes, shows query results in place, and keeps a searchable history. SQL is syntax highlighted.
- **Side panels:** the sidebar and inspector sit in the layout instead of over the table, and can be resized or collapsed with a rubber-band effect. The sidebar is hidden until a file is open.
- **Accent color:** pick the accent color, used for selection, focus and the resize glow, in **Settings → General**.
- **Settings:** a sectioned settings page with icons, and show/hide buttons on secret fields.
- **Inspector:** the copy button is in the header. URL cells get an **Open in Browser** button, and image URLs preview inline.
- **Timestamps:** hover a timestamp to see it in your local time zone.
- **Updates:** **Scan → Check for Updates…** and an automatic daily check offer new GitHub releases. In Terminal, `scan upgrade` installs the latest release, `scan upgrade --check` only reports, and `scan --version` prints the installed version.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.4.0-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
