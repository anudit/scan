Scan v1.0 is a native, read-only macOS data viewer.

- Open Parquet, CSV, TSV, JSONL, gzip-compressed CSV/TSV/JSONL, SQLite and DuckDB files.
- Filter with SQL expressions, sort multiple columns, group and aggregate data, and export the current view as CSV or Parquet.
- Preview files with Finder Quick Look and open them from the optional `scan` CLI.
- Ask questions using Apple's on-device Foundation Models when available.
- Includes the tested tailored DuckDB build: JSON, Parquet, core functions and ICU, with unused autocomplete omitted.

## Requirements

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available. No Intel build is included.

## Installation

Download **Scan-v1.0-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. The ZIP is an alternative and also includes the optional `bin/scan` CLI; copy it to a directory on your `PATH` after installing the app.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are supplied in **SHA256SUMS.txt**. From the download directory, use `shasum -a 256 -c SHA256SUMS.txt` to check both archives; both files must be present for that command.

## Validation

All 21 tests passed, including the million-row Parquet paging check, plain/gzip JSONL, database readers, filtering, sorting, grouping, export and read-only behavior. Additional timezone and collation probes match the original DuckDB build. App signatures and extracted ZIP/DMG contents were verified. The tailored library reduces bundle size; benchmark results do not demonstrate a meaningful query speed improvement.
