Scan v1.4.1 shows SQL results in the main view, refines the window and settings design, makes the accent color apply everywhere, and formats detected UUIDs, dates, timestamps, URLs and emails.

## New in v1.4.1

- **SQL results in the main view:** SQL and Ask results replace the table instead of squeezing into the panel. **Back to table** returns to the table, and the row count in the panel header shows the result again.
- **Detected values:** text columns holding UUIDs, timestamps, dates, URLs or emails are recognized and shown in a readable form, with the type in the column header. Timestamps that are all midnight UTC are shown as dates. Turn it off in **Settings → General → Format detected values**. Your data is unchanged.
- **Window:** the title bar uses the app's colors, tabs flow into the table card, the traffic lights and title line up, and **+** sits after the last tab. Export moved to the toolbar, and file tabs show the file type's icon.
- **Accent color everywhere:** selection, focus rings, links, icons, switches, checkboxes, buttons, the resize glow and SQL keywords follow the accent color, and update as soon as you change it.
- **Settings:** a redesigned settings window with a section sidebar, theme previews, accent swatches with a custom color picker, and switches.
- **Sidebar:** Files was removed and column search collapses into an icon.
- **SQL panel:** no longer gets cut off in short windows, and its empty states are gone.
- **Fix:** `scan upgrade` now also updates the `scan` command installed from the ZIP, starting with upgrades from this version.

## Requirements and installation

Apple Silicon Mac (M1 or later), macOS 14 or later. Ask additionally requires macOS 26 or later with Apple Intelligence available.

Download **Scan-v1.4.1-macos-arm64.dmg**, open it, and drag **Scan.app** to **Applications**. Quit an existing Scan instance before replacing it. The ZIP is an alternative and includes the optional `bin/scan` CLI. If you have the CLI, `scan upgrade` installs this release.

The app is ad hoc signed, **not Developer ID signed or notarized**. If macOS blocks the first launch, try opening Scan, then choose **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in **SHA256SUMS.txt**. With both archives in the download directory, run `shasum -a 256 -c SHA256SUMS.txt`.
